# 📸 CuteCamera

A minimalist digital camera built using the **Seeed Studio XIAO ESP32S3 Sense** and a **1.28" GC9A01A round TFT display**.

The goal of this project is to create a premium pocket camera experience with a clean interface, smooth animations, and no unnecessary UI clutter.

---

## ✨ Features

- 📷 Live camera preview
- ⚡ One-button photo capture
- 🎞️ Custom shutter animation
- 🎨 Minimal UI (camera-first experience)
- 🖥️ 240×240 round display support
- ⚙️ Modular C++ architecture
- 🚀 Optimized for ESP32-S3

---

## 🛠️ Hardware

- Seeed Studio XIAO ESP32S3 Sense
- OV3660 Camera
- 1.28" GC9A01A Round TFT Display
- Tactile Buttons
- MicroSD Card *(planned)*
- LiPo Battery *(planned)*

## 🎯 Design Philosophy

CuteCamera focuses on simplicity.

Instead of filling the display with icons, counters and overlays, the user sees only the photograph.

The camera UI is designed to feel like a compact digital camera rather than a smartphone app.
